## 探测方法和结果

使用训练环境 torch 2.10.0+cu129，每卡独立进程、30 秒超时；检查 65,536 个 float32 元素的 `x * 2 + 1`，以及 256×256 全一矩阵乘法，均同步并核对结果。八卡全部正确返回、退出码均为 0，无 stderr。每卡张量分配峰值约 9.2 MiB（不包含 CUDA 上下文本身）。设备计算能力报告为 12.0。

所有进程正常退出后复查三次，均显示 0% / P8 / 无计算进程；未出现新的 GPU 内核错误。没有执行 GPU reset、驱动重载、重启机器或重新启动 BetaNav 训练。

## 解释 GPU-Util

NVIDIA 将 GPU-Util 定义为采样窗口内至少一个 kernel 执行的时间比例，并非 TFLOPS 或全部计算单元的利用比例。本次无用户显存、无计算进程但持续 100%，加上小上下文退出后恢复，说明之前的读数不能用来判断训练已经用满算力。

参考：[NVIDIA nvidia-smi 文档](https://docs.nvidia.com/deploy/nvidia-smi/)。
