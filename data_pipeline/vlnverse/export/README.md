# 数据集导出（待实现）

输入：通过质量检查、观测和标签严格对齐的 episode。
输出：自包含的 LeRobot 数据、有效标签统计、来源/时间/相机元数据与独立读取验证报告。

导出只负责 schema、索引、分片、媒体与元数据写入，不重新平滑或修复上游轨迹。
明确记录 `fps`、合成秒时间语义、标签 horizon 秒数及采样间隔；
不能直接继承 R2R 的 `fps=1` 帧序号时间约定。

训练读取仍位于 `src/lightnav/dataloader/`；应在无法导入生成代码且采集 scratch 不存在时
独立读取最终数据。最终是否复用现有训练 schema，需等标签定义与时间尺度验证后确定。
