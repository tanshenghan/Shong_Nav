# 训练标签（待实现）

输入：已核验的回放实际机器人/相机位姿、同步 RGB/深度、指令与终点。
输出：FM 连续 waypoint、RVQ token / 解码诊断、apos/opos 目标及各自 mask。

未来目标用明确的秒数和采样间隔定义，再选择模型所需的步数。
默认参考轨迹按每个原始运动间隔采 6 点，不保证全局固定时间间隔；
“后 10 个稀疏点”没有固定秒数，不能将点号乘一个假定的 dt 生成标签。
使用实际回放的时间戳，根据秒级 horizon 选择或重新采样未来位姿。
R2R 的 FM-30 / RVQ-10 步数也不能直接继承；新数据的速度尺度、时间范围、
码本重建误差、终止监督均需独立核验。仅显式 `uniform_time` 模式保证配置的固定采样周期。

机器人局部坐标采用前向米、左向米、逆时针 yaw 弧度。FM 使用实际未来位姿，
不以 RVQ 解码结果作为连续 GT。相机投影必须使用每一帧实际外参和深度，
不可见、未知、尾部不足等情况各自保留定义和 mask。

这里不下载场景、不控制模拟器、不写最终 LeRobot 数据集。
公共几何确有稳定复用需求时再提取，避免将 VLNVerse 强制接到 R2R 的离散步数约定。
